三步走完一轮打样

工作台里照着做一遍就行，不需要装任何插件。

  1. 01

    上传产品照片

    把实物照片拖进对话框，作为参考。本期先用参数量化成品，图生 3D 走可插拔 Provider。

  2. 02

    说清尺寸与做法

    长宽高、纸板厚、颜色、材质、图案落位，或者直接在对话框里用自己的话说。能落的参数当场落，做不了的如实记成待接入。

  3. 03

    看样并导出

    拖转看比例、切六个面看正投影、看展开图核对刀版，导出刀版 PNG / SVG、UV 贴图 PNG 与模型 GLB。

两套模板，形状不同处理方式也不同

盒体算刀版，服装出版型；不把盒体那套尺寸硬套到别的形状上。

规整盒体

长 4–60 / 宽 4–60 / 高 2–40 cm，纸板厚 0.2–2 mm。默认 30×20×8 cm、白卡纸、0.5 mm。

  • 六面正视图 + RSC 精确刀版展开图
  • 粘口与折叠加余量按纸板厚参与计算
  • 导出刀版 PNG / SVG、UV 贴图 PNG、模型 GLB

服装与织物

短袖 T / 长袖 T / 卫衣 / 手套 / 袜子，尺码档 S–XXL，部位尺寸各款式一套。

  • 正面 / 背面 / 部位标注三视图
  • 换尺码档自动带出基准值，任一项可手改
  • 出平铺版型示意与尺寸表，不出刀版展开图

两套参数互不套用：服装不看长宽高，盒体不看部位尺寸。

这几块本期不做

左栏留着位置、点了给提示，不假装已经有这个能力。

导出的都是能直接用的文件

盒体与服装各有自己的导出项，改动参数后导出状态会重置。

  • 展开图 PNG盒体刀版，带尺寸标注，可印刷
  • 展开图 SVG盒体刀版矢量文件，1:1 厘米尺寸
  • UV 贴图 PNG盒体六面平铺，标出图案位
  • 模型 GLB盒体 / 异形体，按米制真实尺寸
  • 版型示意 PNG服装平铺正面 + 部位标注
  • 尺寸表 PNG服装尺码档与部位数值
